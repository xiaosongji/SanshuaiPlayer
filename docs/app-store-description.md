# App Store 产品描述草稿

## 名称建议

散帅播放器

## 副标题

连接你的自托管个人音乐服务器

## 描述

把分散在自建服务器和个人存储中的音乐，带回一套简洁、现代的 iPhone 体验。

散帅播放器是一款通用个人音乐库客户端。添加你自己的 OpenSubsonic、Navidrome、Airsonic、Gonic、Jellyfin 或兼容 NAS 服务，也可从“文件”导入本机歌曲，即可统一浏览、搜索、收藏，管理歌单和播放队列，并在后台连续播放。

主要功能：

- 同时管理并快速切换多个个人音乐服务器
- 批量导入本机歌曲，自动读取标题、艺人、专辑、封面与歌词
- 动态首页、资料库浏览和跨内容类型搜索
- 原始、无损优先、高质量、标准与省流量串流策略
- 常见音乐格式直放，并通过兼容服务器自动处理 APE、Opus、OGG、WMA、WavPack、TTA 与 DSD 等格式
- 服务端转码、后台播放、锁屏和耳机控制
- CarPlay：在兼容车辆上浏览“现在就听”、资料库和歌单，并使用系统正在播放界面安全控制播放
- 可收起的迷你播放器、同步滚动歌词与队列后 3 首预取
- 顺序/随机播放；旋转手机进入原创沉浸式唱片与歌词舞台，3 秒无操作后自动进入纯动效观赏
- 收藏、歌词、歌单与播放进度同步（视服务器能力而定）
- 密码和访问令牌安全保存在本机 Keychain
- 默认严格 HTTPS，并为自建服务器提供按服务器控制的证书选项

本 App 不提供、托管、聚合或分发任何音乐内容，也不接入公共在线曲库。你需要拥有或获授权访问兼容音乐服务器及其中内容。

## 关键词建议

Navidrome, Subsonic, OpenSubsonic, Jellyfin, NAS, 自托管, 音乐库, 串流, 个人音乐

## 审核备注草稿

App 是用户自备服务器的客户端，不含任何音乐目录或公共内容入口。审核可使用提交方提供的专用测试服务器账号。登录凭据保存在设备 Keychain，不发送至开发者服务器。若审核环境无法访问局域网服务器，应提供公网 HTTPS 测试地址。

CarPlay 仅提供音频 App 的浏览与播放能力，使用系统 `CPTemplateApplicationScene`、列表模板和正在播放模板。连接 CarPlay 后，可从“现在就听”、资料库或歌单选择音乐；驾驶界面不提供登录、服务器配置、导入、编辑歌单或其他复杂操作。上述管理操作只在 iPhone 上完成。
